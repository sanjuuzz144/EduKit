EduKit Student Login
1. Activate the venv.
2. Run: py app.py
3. Admin -> add/edit a student and set a password (minimum 6 characters).
4. Open: http://127.0.0.1:5000/login
5. Login with the student's username + password.
6. Student is redirected to /student/dashboard.

Existing users without a password must have one set by the admin before they can log in.
